# Privacy Policy

Supercell Wx is designed to respect user privacy. This document explains what information the application does and does not collect.

## Information Collection

Supercell Wx does **not collect, store, or transmit personal information about users**.

The application does not include analytics, tracking systems, or telemetry.

## Network Connections

Supercell Wx can connect to remote services in order to retrieve weather data and related information. These connections only occur when initiated by the user or when the user configures the application to access specific services.

When connecting to external services:

- The remote server will typically receive the user's **IP address**, as is standard for any network request.
- Some services may receive a **User-Agent header** identifying the application and environment. This may include:
  - The Supercell Wx version
  - The operating system and version

This information is transmitted only to the remote service being accessed and is not collected or stored by Supercell Wx itself.

## Third-Party Services

Supercell Wx may connect to third-party data providers depending on user configuration. Each service operates under its own privacy policy and logging practices.

Default data providers include:
- Amazon Web Services
- College of DuPage
- GitHub
- Iowa Environmental Mesonet
- Mapbox
- MapTiler
- National Weather Service

Users should review the privacy policies of any services they choose to use with the application.

## Local Data

Supercell Wx may store configuration files and cached data locally on the user's system to support normal operation. This information remains on the user's device and is not transmitted unless the user explicitly shares it.

## Changes

This privacy policy may be updated as the application evolves. Updates will be reflected in this document.
